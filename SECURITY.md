# Sécurité

## Signaler une vulnérabilité

Ne publiez pas les détails d'une vulnérabilité dans une issue ou une discussion publique.

Lorsque le dépôt GitHub sera créé, signalez les problèmes de façon privée via **Report a vulnerability** dans l'onglet **Security** si cette fonctionnalité est activée. Sinon, contactez un mainteneur par un canal privé avant de rendre le problème public.

Incluez les étapes minimales pour reproduire le problème, son impact potentiel et les versions concernées. N'envoyez pas de données réelles, de secrets ni de fichiers confidentiels dans le rapport.

## Portée

Les signalements pertinents comprennent notamment la lecture ou l'exposition non autorisée de fichiers, les accès non prévus aux données téléversées et les problèmes dans le traitement des fichiers importés.

Ce document ne constitue pas une garantie de délai de réponse ou de publication d'un correctif. Le dépôt et ses canaux de signalement ne sont pas encore publics.
